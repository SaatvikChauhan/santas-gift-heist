## Overview

**Santa’s Gift Heist** is a **real-time multiplayer web game** wrapped in a **festive Christmas theme** 🎁❄️.

Players join a shared room, take on secret roles, complete tasks, sabotage progress, discuss suspicions, and vote — all in real time.

Built with a focus on:
- Multiplayer gameplay
- Socket-based real-time interactions
- Immersive UI & animations
- Pure fun

---

## Gameplay

### 👥 Roles
- **🎄 Elf**
  - Complete tasks to save Christmas
  - Identify and vote out the Grinch
- **😈 Grinch**
  - Secretly sabotage tasks
  - Blend in, lie, and survive voting rounds

---

### ⏱ Game Phases
1. **Lobby**
   - Players join using a room code
   - Host starts the game
2. **Action Phase**
   - Elves complete tasks
   - Grinch sabotages secretly
3. **Discussion & Voting**
   - Chat, accuse, defend
   - Vote to eliminate a player
4. **Spectator Mode**
   - Eliminated players watch the chaos unfold 👁

---

### 🎁 Tasks
- **Chaotic Gift Sorting**
- **Carol Memory Mayhem**
- **Reindeer Control Panel**

Each task is interactive, animated, and sabotage-able.
